# Task 9: External libraries and local file read/write

**B4 date in the teaching plan:** 01/10/2026  
**Dart entry file:** `main.dart`

## Run
1. Create/open a Flutter project.
2. Copy this `main.dart` into `lib/main.dart`.
3. Run `flutter pub get`, then `flutter run`.

## Dependency for Task 9
Add this under `dependencies` in `pubspec.yaml`:
```yaml
path_provider: ^2.1.5
```
Then run `flutter pub get`.
